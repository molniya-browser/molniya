# Молния

Открытый браузер для рунета: пересборка релизов Zen Browser (MPL 2.0) с доверенным корневым сертификатом Минцифры из коробки, поиском Яндекс по умолчанию, uBlock Origin и полностью выключенной телеметрией.

- Дизайн-документ: `docs/superpowers/specs/2026-11-05-molniya-browser-design.md`
- План реализации: `docs/superpowers/plans/2026-11-05-molniya-v1.md`

Zen Browser и Mozilla — авторы базового кода. «Молния» — независимая пересборка; товарные знаки Zen Browser не используются.
