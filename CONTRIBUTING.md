# Участие в разработке

«Молния» — не исходники браузера, а инструменты пересборки готовых релизов Zen Browser. Подробный гид по проекту — в [AGENTS.md](AGENTS.md); здесь — самый короткий путь до первой сборки.

## Что понадобится

- Node.js 20+ (npm-зависимостей нет, `npm install` не нужен)
- `curl`, `7z` (на macOS: `brew install p7zip`), `zip`/`unzip`, `xz`, `tar`
- полный пайплайн рассчитан на macOS: артефакты Windows и Linux собираются кросс-платформенно, а macOS-артефакт требует утилит Apple

## Команды

```bash
npm run toolcheck                          # проверить внешние инструменты
npm test                                   # unit-тесты (без сети)
npm run pipeline -- --os mac --tag latest  # сборка → dist/ (долго, качает артефакты)
```

## Карта репозитория

```
src/                  — скрипты пересборки; все константы — в src/config.mjs
detector-extension/   — встроенное расширение-детектор обновлений
landing/              — сайт molniya-browser.ru (GitHub Pages)
assets/branding/      — брендовые картинки для браузера
tests/                — тесты node:test
.github/workflows/    — CI: release и pages
```

## Как выходит релиз

1. Actions → workflow **release** (входы `zen_tag`, `build_n`) → три артефакта и `SHA256SUMS` попадают в draft-release.
2. Ручная приёмка, затем публикация драфта.
3. Обновление uBlock Origin — вручную: проверить новый XPI и обновить `version` и `sha256` в `src/config.mjs`.

## Правила

- ESM и только стандартная библиотека Node.js; новые npm-зависимости — под вопросом.
- Комментарии, сообщения и названия тестов — по-русски; идентификаторы в коде — на английском.
- Общие константы держите в `src/config.mjs`, а не дублируйте по модулям.
- Fail-fast: неполный или непроверенный артефакт не считается успешной сборкой.
- Перед коммитом — `npm test`.
