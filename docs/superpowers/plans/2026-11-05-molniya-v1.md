# Молния v1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выпустить v1 браузера «Молния» — пересборку релизов Zen Browser с сертификатами Минцифры, русскими дефолтами и своим брендом, с раздачей через GitHub Releases и лендинг molniya-browser.ru.

**Architecture:** Пайплайн на Node.js (ESM, без runtime-зависимостей) скачивает официальные артефакты Zen, распаковывает их, патчит бренд (omni.ja + Info.plist), кладёт `distribution/` (policies.json + autoconfig + сертификаты + uBlock + langpack + расширение-детектор), запаковывает обратно. CI (GitHub Actions, матрица mac/linux/windows) воспроизводит это для трёх ОС и публикует Release. Лендинг — статический HTML на GitHub Pages.

**Tech Stack:** Node.js ≥ 20 (ESM, `node --test`), внешние бинарники: `curl`, `7zz` (p7zip), `zip`/`unzip`, `xz`, `hdiutil`+`codesign`+`iconutil` (macOS), `tar`. GitHub Actions. Vanilla HTML/CSS для лендинга.

**Spec:** `docs/superpowers/specs/2026-11-05-molniya-browser-design.md` — план аргументирует от спеки; исполнители читают обе.

## Global Constraints

- Node ≥ 20, ESM-модули, ноль runtime-зависимостей из npm (только stdlib + внешние бинарники).
- Upstream: `zen-browser/desktop` (GitHub). Артефакты: win=`zen.installer.exe`, mac=`zen.macos-universal.dmg`, linux=`zen.linux-x86_64.tar.xz` (канал stable).
- Сертификаты Минцифры — только с `https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt` и `.../russian_trusted_sub_ca_pem.crt`, SHA256-пины в `src/config.mjs`.
- Телеметрия/эксперименты/отчёты — off; Safe Browsing, списки отзыва, обновления расширений с AMO — on (не выключать!).
- Родной апдейтер Zen — off (`DisableAppUpdate` + prefs-дубли).
- Все видимые пользователю строки бренда `Zen Browser`/`Zen` → «Молния». Атрибуция Zen Browser и Mozilla (MPL 2.0) обязательна на лендинге и в about.
- Поиск: Яндекс по умолчанию, DuckDuckGo — в один клик. Локаль: `ru` форсирована + официальный Firefox-лэнгпак.
- Версия/тег Молнии: `<zenTag>-molniya.<n>`, например `1.24b-molniya.1`. Имена файлов артефактов — латиницей: `molniya-<версия>-{win.zip,mac.dmg,linux.tar.xz}`.
- GitHub: org `molniya-browser`, репо `molniya`. Домен: `molniya-browser.ru` (CNAME на GitHub Pages).
- Тесты: `node --test tests/` зелёные перед каждым коммитом.

## Review Focus

1. GitHub API недоступен (офлайн/блокировка) → детектор обновлений молчит, не спамит ошибками, не ломает браузер. Тест: Task 5, `decideUpdate` с ошибкой сети.
2. У пользователя уже стоит Zen/Firefox → Молния не трогает их профили и деинсталляции. Шаги: Task 4 (чек-лист сосуществования), Task 9 (Windows — portable zip, реестр не затрагивается).
3. Сертификат Минцифры на gu-st.ru заменён/ротирован → пайплайн падает с внятной ошибкой, а не молча тащит чужой файл. Тест: Task 3, `CertPinError`.
4. Zen переименовал/убрал ассет в релизе → fetch падает списком имеющихся ассетов, релиз не собирается частично. Тест: Task 2, `MissingAssetError`.
5. DMG после патча сломан (подпись/образ) → пайплайн сам это ловит. Шаги: Task 8, `hdiutil verify` + `codesign --verify` в пайплайне.
