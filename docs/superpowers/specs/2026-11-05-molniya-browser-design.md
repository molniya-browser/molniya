# Молния — дизайн-документ браузера

- Дата: 2026-11-05
- Статус: ожидает утверждения партнёром
- Автор проекта: Иван Глушков (соло, фронтенд JS/TS)

## Замысел и зачем

Русский пользователь десктопа стоит перед плохим выбором:

- **Chrome/Edge/Firefox** — западные браузеры после ухода удостоверяющих центров из России показывают «Ваше соединение не защищено» на госуслугах, сайтах банков и госсервисах, использующих сертификаты российского УЦ Минцифры.
- **Яндекс.Браузер** — сертификаты из коробки есть, но это закрытый код, телеметрия, реклама и агрессивное продвижение экосистемы.

«Молния» — третий путь: открытый браузер с красивым минималистичным UI в духе Zen Browser, где корневой сертификат Минцифры доверен из коробки, телеметрии нет, а код открыт.

Аудитория v1: массовый русский пользователь десктопа (Windows в первую очередь), не гик. Продукт публичный: выкладываем для людей, цель — массовая замена Chrome/Яндекса для тех, кому важны красота, открытость и работающие госсайты.

Успех v1: **1000 скачиваний + живая обратная связь** (issues на GitHub, Telegram, письма). Дальше — посмотрим.

## Решения партнёра (зафиксированы в разговоре)

1. **Дорога Б для v1**: не собственный форк, а пересборка официальных релизов Zen Browser под своим именем. Лицензия MPL 2.0 это разрешает (с условием переименования и атрибуции). Быстрый релиз и проверка спроса.
2. **Дорога А параллельно**: учиться собирать из исходников, переехать на настоящий форк со своим каналом обновлений после того, как продукт докажет себя (критерий — успех v1).
3. **Имя**: «Молния» / Molniya. Ассоциация: советский спутник + молния = скорость. Ассоциация с дронами в новостях обсуждена и принята осознанно.
4. **Домен: molniya-browser.ru — единственный** (лендинг, почта, всё для продукта). Другие домены не берём. Браузерные аналоги molniya.ru, молния.рф, molniya.io заняты — проверено, это принято.
5. **GitHub-организация**: `molniya-browser` (свободна, проверено). Telegram: `molniya_browser` (проверить руками, из сети ассистента не видно).
6. **Платформы v1**: Windows, macOS, Linux — как у Zen. Мобильных нет.
7. **Поиск по умолчанию: Яндекс** — то, чего ждёт русская аудитория. DuckDuckGo — на виду, переключение в один клик (иконка в строке поиска + на стартовой).
8. **Сертификат Минцифры — вшит из коробки**: госуслуги, банки, госсайты без предупреждений.
9. **Доставка обновлений на установленные копии** (решение по итогам проверки строителем): встроенное расширение-детектор — раз в день опрашивает GitHub Releases и показывает баннер «доступно обновление» со ссылкой на скачивание. Полноценный собственный update-канал — на дороге А.
10. **Язык интерфейса**: русский форсируется + официальный Firefox-лэнгпак (ядро переведено полностью); недостающие строки собственного UI Zena остаются английскими временно, добираем собственным переводом постепенно.
11. **Граница «никакой слежки»**: выключена телеметрия, эксперименты, отчёты, продвижение. Защитные сетевые проверки включены: Safe Browsing (фишинг-листы), списки отзыва сертификатов, живые обновления расширений (uBlock Origin обновляется с AMO). Лендинг объясняет это различие явно и честно.

## Дефолты исполнителя (озвучены, не отвергнуты)

1. Стартовая страница — штатная Zen, плитка популярных русских сайтов (VK, YouTube, Ozon, Wildberries, Mail.ru, Госуслуги...).
2. uBlock Origin предустановлен из коробки.
3. Телеметрия полностью выключена (Mozilla-телеметрия и всё, что может быть в Zen).
4. Раздача: GitHub Releases + лендинг на molniya-browser.ru (GitHub Pages или Cloudflare Pages), код и pipeline в GitHub-орг molniya-browser.

## Нецели v1 (осознанно не делаем)

- Мобильные платформы (Android/iOS) — нет и не планируется до успеха десктопа.
- ГОСТ-криптография уровня КриптоПро (ГОСТ-TLS) — вне scope; доверие корню Минцифры ≠ ГОСТ-стек.
- Собственная синхронизация — нет.
- Свой магазин расширений — нет (используем addons.mozilla.org).
- Монетизация — никакой, включая платное место под поиск (партнёрские деньги без трафика всё равно не дают).

## Ограничения

- **Один человек, фронтенд (JS/TS)**: UI-часть браузера (JS/XUL/HTML) — по силам; C++/Rust-сборка — пока нет, поэтому v1 не требует пересборки исходников. Тяжёлые операции — CI.
- **Бюджет минимален**: домен ~350 ₽/год; код-подпись сборок может стоить денег (см. Риски) — опционально.
- **Лицензия MPL 2.0**: пересборка и распространение разрешены, чужие торговые марки (Zen, Firefox лого и пр.) — нет. Все видимые пользователю упоминания бренда должны быть заменены на «Молния», атрибуция Zen Browser обязательна (на сайте и в about).
- **Обновления**: движок Zen обновляется каждые ~4 недели + security-патчи Mozilla. Пересборка затирается чужим апдейтером — см. Обновления ниже.

## Что осталось строителю (его решения, план будет в superpowers:writing-plans)

### Механика пересборки (ядро проекта)
- Взять официальные артефакты релиза Zen (Windows-установщик, macOS .dmg, Linux-сборка), распаковать.
- **Патч бренда**: все видимые пользователю строки «Zen Browser» → «Молния» (заголовки, about:support, меню, дефолтный профиль). Основной механизм — правка `omni.ja` и/или `distribution/` внутри установки. Имена файлов (.app, .exe, ярлыки) — по возможности.
- **distribution/-папка** (механизм Firefox):
  - `policies.json`: установка сертификата Минцифры (`Certificates.Install` на .crt в комплекте), отключение телеметрии, отключение Zen-апдейтера (`app.update.enabled=false` и связ.), запрет любых загрузок данных.
  - дефолтные prefs: поиск Яндекс по умолчанию + DDG в списке, стартовая с русской плиткой, uBlock Origin как встроенное расширение.
- Запаковать обратно в установщики для трёх ОС (NSIS-пересборка / DMG через hdiutil / tar для Linux), SHA256-суммы.
- Техническая разведка (spike) в начале: проверить на всех трёх ОС, что (а) сертификат встаёт из policies.json, (б) поиск-по-умолчанию переопределяется, (в) бренд-строки заменяются без пересборки исходников, (г) Zen-апдейтер выключается. Если что-то из этого невозможно без исходников — зафиксировать и обсудить эскалацию на дорогу А раньше плана.

### Обновления (ключевое решение)
- Рекомендация: **автоматическая перепаковка каждого релиза Zena** в CI (watch тегов upstream → fetch → repack → release). В v1 допустим ручной триггер релиза; цель v1.1 — полный автопилот «нажал кнопку».
- Никогда не оставлять включённым родной апдейтер Zen (иначе он перезапишет Молнию или сломает её).

### Подписи и доверие ОС
- Windows без подписи = предупреждение SmartScreen; macOS без подписи = Gatekeeper (обходится правым кликом, но это трение). На старте принять трение (написать честный FAQ «как открыть»), код-подпись (Azure Trusted Signing / EV) — отложить до подтверждённого спроса; пересмотреть при первых жалобах.

### Лендинг molniya-browser.ru
- Одностраничник: что это, скриншоты, кнопки скачивания по ОС (GitHub Releases), FAQ (SmartScreen, «почему без подписи», «что с моими данными — ничего»), атрибуция Zen Browser и Mozilla (MPL), ссылка на код.

## Риски (названы открыто)

1. **Окно уязвимости**: между security-патчём Mozilla/Zen и нашей перепаковкой проходят дни. Автоматизировать pipeline — приоритет №1 после релиза.
2. SmartScreen/Gatekeeper-трение без подписи может резать конверсию «скачал → установил».
3. Zen может сменить политику релизов/лицензии/товарных знаков — мониторить upstream.
4. Сертификат Минцифры обновляется (крест-сертификация) — обновление .crt в пайплайне держать ручкой, не забыть в чек-листе релиза.
5. Слово «Молния» обычное — конкурентов в других категориях хватает; в категории браузеров чисто. Раз в месяц поглядывать.
6. Соло-выгорание: процесс должен быть автоматизирован до «одной кнопки», иначе через полгода умрёт.

## Проверка строителем (builder check) — принятые решения

Документ прочитан независимым ревьюером-строителем. Часть его вопросов закрыта решениями исполнителя (мои звонки, партнёр может отвергнуть при чтении):

1. **Сосуществование с Zen/Firefox** — Молния обязана ставиться рядом с Zen и Firefox, не ломая их: отдельные идентификаторы установки (registry/uninstall-записи Windows, bundle ID macOS), отдельный корень профиля. Spike проверяет конфликт установки отдельно от бренд-строк. Если полная смена ID невозможна перепаковкой — это заранее известная эскалация на дорогу А, а не сюрприз.
2. **Бренд-ассеты** — готовых нет; в план закладывается задача создать иконку/логотип Молнии (варианты делаем вместе с партнёром). Релиз блокируется без готового набора иконок — зеновые оставлять нельзя (товарный знак).
3. **Импорт данных из Chrome/Яндекса при первом запуске** — штатный мигратор Firefox; проверить его работу в spike.
4. **Linux в v1** — только tar.xz, без .deb/Flatpak (как зафиксировано выше, упаковка Linux — простой архив).
5. **Upstream-механика** (дефолты ревьюера приняты): канал Zen stable; проверка SHA256 артефактов upstream; ad-hoc переподпись .app для macOS после правок; в комплект кладём актуальный официальный набор корней Минцифры.
6. **Дорога А** — по прямому решению партнёра из разговора: параллельный лёгкий учебный трек «несколько часов в неделю, без вех и дедлайнов», не блокирует v1 и не входит в её критический путь.
